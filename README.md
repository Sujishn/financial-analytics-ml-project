
# An Integrated Machine Learning Framework for Forecasting University Financial Performance  
### (High‑Level Overview — Full Code Withheld Due to Publication Review)

This repository provides a high-level summary of my research project, which develops an
integrated machine learning framework to forecast university financial performance using
multi-year institutional data. The full code, dataset, and detailed methodology are not
publicly available due to ongoing publication review.

## Project Summary
This study builds a forecasting pipeline that combines traditional time‑series techniques
with modern machine learning models to predict key financial indicators such as operating
expenses, operating margin, and budget balance. The framework incorporates structural
break analysis to account for major institutional events that significantly alter financial
patterns.

### Key Components
- **Structural Break Analysis:**  
  Identifies major shifts in financial behavior (e.g., the 2012 UMDNJ integration and the
  2020 COVID‑19 disruption). These breakpoints are incorporated into the modeling pipeline
  through dummy variables and segmented feature engineering.

- **Feature Engineering:**  
  Includes lagged variables, growth rates, per‑student metrics, and event‑based indicators
  to capture both long‑term trends and short‑term shocks.

- **Machine Learning Models:**  
  Evaluates multiple supervised learning models (e.g., Ridge Regression, Random Forest,
  Gradient Boosting) to forecast financial outcomes and compare performance against
  traditional baselines.

- **Forecasting & Insights:**  
  Produces multi‑year forecasts that highlight structural deficits, cost pressures, and
  enrollment‑sensitive dynamics in university finances.
